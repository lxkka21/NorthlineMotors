# Raw AI prompts and chat logs

The assignment requires this file to contain raw, unedited AI chat logs or public links to those logs. A raw conversation export or public link was not supplied to this repository, so no conversation has been reconstructed or fabricated here.

## How to assemble this file correctly

1. Export the complete conversation from the AI tool used for this project, or obtain a public read-only conversation link.
2. Preserve the original wording, order, timestamps, tool messages, and assistant responses. Do not summarize, clean up, or rewrite the content.
3. Remove or redact only secret values, personal credentials, private URLs, tokens, and other sensitive data. Record that redaction occurred without replacing the text with a summary.
4. Paste the redacted raw log below this instruction, or add the public links with their source and date.
5. Review the file for Supabase keys, JWT secrets, passwords, database connection strings, and user data before committing.
